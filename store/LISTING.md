## Name

SideComments for YouTube

## Short description

Move YouTube™ comments to the right and recommendations below the video. Works in normal and theater mode.

## Detailed description

Read the conversation beside your video. SideComments for YouTube™ moves the
existing comments section into the right sidebar and places recommended videos
below the video description.

Features:
- Comments on the right in the desktop two-column watch layout.
- Recommended videos below the video instead of in the sidebar.
- Normal and theater mode support. Theater mode keeps the wide player at the
  top, with comments on the right of the content beneath it.
- A boxed comments panel that scrolls independently and keeps a limited height
  as YouTube loads more comments.
- Light and dark appearances that follow YouTube's selected theme.
- A toolbar switch to turn the layout on or off.
- The original layout returns on narrow windows and in fullscreen.

The extension rearranges YouTube's existing page elements. YouTube still
provides the video, recommendations, comments, sorting, and reply controls.
The extension starts early, but it cannot make YouTube's comment data load
instantly.

Privacy: the current YouTube page structure and path are processed locally to
perform the layout change. The only saved extension setting is the on/off
preference. The extension does not send page information to the developer,
build a browsing-history log, or use analytics, advertising, or remote code.

Works on the desktop www.youtube.com watch layout. Shorts, embedded players,
the mobile site, and alternative YouTube layout experiments are outside scope.
Other extensions or future YouTube changes may affect compatibility.
